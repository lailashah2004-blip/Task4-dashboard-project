#  COVID-19 Dataset – Tableau Visual Story 

This project is a **6-chart Tableau visual story** created using a COVID-19 dataset. The goal of this project is to transform raw COVID-19 data into meaningful visualizations that highlight **trends, patterns, comparisons, and geographical insights**.

##  Project Overview

The Tableau Story presents six different visualizations that work together to create a clear narrative around the impact and spread of COVID-19.

###  Visualizations Included

1. **COVID-19 Trend Analysis** – Shows how COVID-19 cases changed over time.
2. **Geographical Map** – Visualizes the distribution of COVID-19 cases across different locations.
3. **Regional Comparison** – Compares COVID-19 figures across different regions.
4. **Case Distribution Analysis** – Highlights differences in the magnitude of reported cases.
5. **Time-Based Comparison** – Examines patterns and changes across different periods.
6. **Interactive Summary Dashboard** – Brings the key findings together into a connected visual story.

##  Objectives

* Practice data visualization using **Tableau**
* Identify important trends and patterns in COVID-19 data
* Explore geographical differences
* Present data-driven insights through an easy-to-understand visual narrative
* Develop skills in dashboard and story creation
